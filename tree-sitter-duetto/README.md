# tree-sitter-duetto

A [tree-sitter](https://tree-sitter.github.io/) grammar for Duetto, for
syntax highlighting and other editor support. The reference parser is
`lib/parser.mly`; this grammar follows it, but is more permissive where a
check needs a whole construct, such as "a block has no fields".

- `grammar.js` is the grammar, the only file edited by hand.
- `src/` is generated by `tree-sitter generate`, and committed, since editors
  compile `src/parser.c` without running the generator.
- `queries/highlights.scm` holds the canonical highlighting queries. Editor
  extensions, such as `editors/zed`, keep their own copies.
- `test/corpus/` holds tree-sitter's tests: a source and its expected tree.

With the tree-sitter CLI installed (`npm install -g tree-sitter-cli`):

```sh
tree-sitter generate   # after editing grammar.js
tree-sitter test       # run test/corpus
tree-sitter parse ../test/duetto/accepted-specs.duetto
```
